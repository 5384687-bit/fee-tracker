# מעקב שכר טרחה

אפליקציית ניהול שכר טרחה למשרד עורכי דין. עצמאית לחלוטין — לא קשורה לשום מערכת אחרת.

קובץ אחד: `index.html`. אין התקנה, אין שרת, אין תלויות.

## מה היא עושה

- **לקוחות** — שם, טלפון, ת״ז, אימייל, הערות
- **תיקים** — לכל תיק שכר טרחה שנקבע בנפרד, עם בחירה בין "בתוספת מע״מ", "כולל מע״מ" ו"ללא מע״מ"
- **תשלומים** — פריסה אוטומטית לתשלומים חודשיים, או הזנה ידנית של כל תשלום
- **מעקב גבייה** — כמה נגבה, כמה נשאר, מה באיחור, מה מגיע ב־30 הימים הקרובים
- **דוחות** — גבייה חודשית ל־12 חודשים, פילוח לפי לקוח ולפי סוג תיק
- **ייצוא** — CSV לאקסל, גיבוי JSON מלא

## אבטחה

כל הנתונים מוצפנים ב־AES-GCM 256 ביט. מפתח ההצפנה נגזר מהסיסמה שלך
באמצעות PBKDF2 עם 250,000 סיבובים.

הסיסמה עצמה **לא נשמרת בשום מקום** — לא בקובץ, לא בענן, לא בשרת.
המשמעות: אין "שכחתי סיסמה". אם הסיסמה תאבד, הנתונים לא ניתנים לשחזור.

מה שנשמר בענן הוא בלוק מוצפן בלבד. מי שיפתח את הקישור יראה טקסט חסר משמעות.

## הפעלה

לחיצה כפולה על `index.html` — זהו.

## סנכרון בין מכשירים

כדי לראות את אותם נתונים גם מהטלפון:

1. נכנסים ל־npoint.io
2. מדביקים בתיבה `{}` ולוחצים Save
3. מעתיקים את הכתובת שנוצרה (מתחילה ב־api.npoint.io)
4. באפליקציה: ⚙️ הגדרות ← כתובת הסנכרון ← הדבקה ← שמירה
5. במכשיר השני: אותה כתובת, אותה סיסמה

## גיבוי

הגדרות ← הורדת גיבוי. מומלץ פעם בחודש.
קובץ הגיבוי אינו מוצפן — לשמור במקום בטוח.
